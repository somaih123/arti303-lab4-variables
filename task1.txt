Task 1 - Unification

?- house = house.
true.
Explanation: same constant.

?- house = abc.
false.
Explanation: different constants.

?- edge(a,b) = edge(C,b).
C = a.
Explanation: same functor/arguments; C = a.

?- edge(a,d) = edge(C,B).
C = a, B = d.
Explanation: same functor/arguments.

?- edge(C,B) = edge(a,d).
C = a, B = d.
Explanation: unification works both ways.

?- edge(A,f(g,h)) = edge(a,B).
A = a, B = f(g,h).
Explanation: B unifies with a structure.

?- edge(A,A) = edge(b,c).
false.
Explanation: A can't be b and c.

?- edge(A,A) = edge(b,b).
A = b.
Explanation: both sides match A = b.

?- A = B, B = f.
A = f, B = f.
Explanation: A, B linked.

?- A = B, B = f, A = e.
false.
Explanation: A already f, not e.
